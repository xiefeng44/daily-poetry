# 每日一诗

安卓锁屏诗词应用，目前为个人及朋友试用的测试版。已按 vivo X100 Ultra / OriginOS 4 的锁屏布局设计。

## 下载与安装

[下载 0.4.1 安装包（约 133 MB）](https://github.com/xiefeng44/daily-poetry/releases/download/v0.4.1/daily-poetry-0.4.1.apk) · [版本说明](https://github.com/xiefeng44/daily-poetry/releases/tag/v0.4.1)

请直接覆盖旧版本，不要先卸载，以保留设置。首次安装后打开应用，点“设为锁屏并开启每日换诗”。请允许自启动及后台运行；系统省电限制可能延迟自动换诗。仅更换锁屏图片，指纹、时钟和解锁由系统管理。

## 功能

- 离线每日换诗、手动换一首、诗词解读与诗人介绍。
- 精选展示池 1,619 首：S 350 首 / A 850 首 / B 419 首，随机概率 30% / 50% / 20%，近期作品避免重复。
- 保留完整原始诗库。文学筛选分值属于程序规则代理，不代表逐首文学评判。
- 0.4.1 已内置版本检查地址。每天打开时检查一次，也可点“检查应用更新”。确认下载后，返回应用点“安装已下载的更新”；校验文件后由安卓系统询问安装。首次需要允许本应用安装更新。
- 诗词库暂随安装包更新，无账号；诗词阅读及锁屏生成可离线使用。
